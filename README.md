# ECI Hearing & Notice Monitoring Dashboard

Professional monitoring dashboard for ECI hearing, notice generation, notice delivery, and DEO status reporting.

## Intended workflow
1. Download the latest ECI Excel export.
2. Upload it to the dashboard.
3. The application validates the 430 polling stations.
4. Current ECI status is combined with the fixed master PS mapping.
5. Dashboard and operational reports update automatically.

## Core reporting
- PS-wise status
- Anomaly / No Mapping split
- Notice Generated / Pending Generation
- Notice Delivered / Pending Delivery
- Hearings Held and lapsed dates
- DEO status
- Hearing-centre, officer, supervisor and BLO views
- Validation and reconciliation
- Upload history and change tracking
